# node-cli-rag

This example targets the v4 CLI workflow: inspect, verify, migrate, and receipt
output are available alongside normal deterministic queries.

The CLI also exposes read-only V5 Knowledge Image inspection and the KIP-0026
Studio management snapshot. See the [V5 roadmap](../../docs/ROADMAP.md).

Minimal CLI retrieval flow using workspace `@knolo/cli`.

```bash
npm install
npm run build-pack && npm run query
```
