# contracts-demo

Redistributable hand-authored example. It is not a customer matter and it is not universal contract coverage.

The Knowledge Image has two passages. One permits cancellation. One prohibits it. The plan maps `permits` to support and `prohibits` to opposition. KAR keeps both in the selected set when the floors ask for each requirement.

`dossier/evidence.md` is the Evidence Dossier. `knolo kar dossier verify dossier` prints `VERIFIED` when the directory is unchanged.

Regenerate from the repository root with `node examples/kar-v6/run.mjs`.
