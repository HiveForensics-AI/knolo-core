# Knolo 6.1.0

6.1.0 adds offline verifiable composition and attestation. It does not move the `v6.0.0` tag. KAR semantics stay `kar-1-research-1`. V5 `stateRoot` is unchanged.

## Packages

These packages are `6.1.0`: `@knolo/core`, `@knolo/cli`, `@knolo/langchain`, `@knolo/llamaindex`, `@knolo/semantic-ollama`, and `create-knolo-app`.

Their `@knolo/*` dependency ranges stay `^6.0.0`. `@knolo/reflex` stays `0.2.0`. `@knolo/evidence-gate` stays `0.1.0`. `@knolo/openclaw` stays `0.1.0` on `@knolo/core` `^5.5.1`. Rust, Python, and the ICP canister stay `5.5.1`.

Publishing, and any new git tag, are separate steps.

## What landed

Import `@knolo/core/composition`.

- `composition-record-1` cites images, packs, KAR sidecars, Domain Packs, excerpts, and nested records.
- `composition-excerpt-1` commits at most 64 object ids and kinds.
- `composition-attestation-1` commits `mount`, `used`, or `cited`.
- `composition-signature-1` is an optional one-signer Ed25519 envelope.
- `knolo compose`, `knolo attest`, and `knolo verify-attestation` are offline.

`used` means a query or a KAR evaluation ran. It does not mean `SATISFIED`, and it does not mean a claim is true or false. Hub `attested: true` remains a listing flag.

## Out of this version

Marketplace payment, royalties, zero-knowledge disclosure, Merkle inclusion, merged evidence graphs, and a V5 commit-view key named `composition` are not in 6.1.0. Hub verify still accepts only V4 and V5 bytes.
