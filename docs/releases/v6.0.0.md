# Knolo 6.0.0

Knolo V6 introduces KAR: deterministic evidence-set retrieval over committed knowledge.

This is the general-availability release. `6.0.0-rc.1` remains the historical prerelease. Domain Pack automatic extraction stays `review-required`. npm publish is not part of this commit.

## Overview

V6 packages the existing architecture:

```text
Knowledge Image
  → CEG Source
  → Committed Evidence Graph
  → KAR minimum evidence set
  → Evidence Dossier
  → independent verification
```

KAR is not a ranked-passage search, a better BM25, or a vector index. It asks for the minimum applicable evidence set required to evaluate a proposition under a declared plan.

## KAR

Import `@knolo/core/kar`:

```ts
import { createKarSession, evaluateKar, verifyKar, explainKarResult, createKarDossier } from '@knolo/core/kar';
```

Semantics remain `kar-1-research-1`. `SATISFIED` means evidence requirements were satisfied. `UNSATISFIED_EVIDENCE_REQUIREMENTS` means they were not. Abstention is a result.

`@knolo/core/experimental/kar` stays operational for this cycle.

## Committed Evidence Graph

The runtime graph is a `KarSidecarV1` sidecar. `compileCegSource()` is still the only writer of those bytes. `SemanticRoot` binds the graph to `KnowledgeRoot`. V5 `stateRoot` stays a different digest.

## CEG authoring

Import `@knolo/core/kar/authoring` for `createCegSource`, `compileCegSource`, `validateCegSource`, `lintCegSource`, and `diffCegGraphs`. The experimental authoring entry remains.

## Domain Packs

Bundled packs are contracts v4, policy v4, and operations v4. Maturity is `review-required`, recorded in `domains/v6-catalog.json`. Packs contain rules, vocabulary, plan templates, fixtures, and a README. They do not contain customer evidence.

`AUTO_ACCEPT`, `NEEDS_REVIEW`, and `OBSERVATION_ONLY` are unchanged. Relation-producing v4 rules are not auto-accepted.

## Evidence Dossiers

`createKarDossier({ image, graph, plan, proposition })` returns the five frontiers, the selected minimum set, why it was selected, the certificate roots, and a manifest. The status sentences are `Evidence requirements satisfied` and `Evidence requirements not satisfied`.

## Verification

`verifyKar` and `knolo kar dossier verify` recompute the certificate. A changed root or a changed dossier sentence fails closed. Verification does not establish real-world truth.

## Browser

`@knolo/core`, `@knolo/core/kar`, and `@knolo/core/kar/authoring` bundle without Node filesystem imports. Filesystem helpers stay on `@knolo/core/node` and the CLI.

## CLI

`knolo kar` gains `demo` and `conformance`. `knolo --version` prints the CLI version and the resolved `@knolo/core` version. `--json` remains the machine-readable mode. Verify commands exit non-zero on failure. Evaluate exits 0 for abstention.

## Migration

See [docs/kar/migration-v6.md](../kar/migration-v6.md). Workspace ranges that follow `@knolo/core` use `^6.0.0`.

## Compatibility

Ordinary Knolo retrieval is unchanged: lexical query, BM25, MMR, semantic reranking, V4 packs, V5 images, mounting, migration, EQL, VQF, Reflex, and Evidence Gate.

`@knolo/reflex` stays `0.2.0`. `@knolo/evidence-gate` stays `0.1.0`. Their `@knolo/core` range is `^6.0.0`. Rust `knolo-core-rust` and Python `knolo` stay `5.5.0`. They do not implement KAR.

Node engines stay `>=20` for the CLI, matching CI. `@knolo/semantic-ollama` stays `>=18`.

## Performance

Closure, exact-cover, tamper, and compiler determinism are conformance gates, not Domain Pack accuracy claims. Split timings live in [docs/kar/V6_PERFORMANCE.md](../kar/V6_PERFORMANCE.md). Recorded gate results live in [docs/kar/V6_RELEASE_READINESS.md](../kar/V6_RELEASE_READINESS.md). The published research scale file is not rewritten.

## Limitations

Human gold is incomplete. Do not treat Domain Pack extraction as validated. See [docs/kar/limitations.md](../kar/limitations.md) and [docs/kar/security.md](../kar/security.md).

## Semantic production validation

Initial Domain Packs are experimental and review-oriented. KAR itself operates deterministically over the committed graph regardless of how the graph was produced.
