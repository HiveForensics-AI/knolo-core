# Knolo 6.2.0

6.2.0 adds Knolo Cortex, reasoned evidence retrieval, as `@knolo/core/cortex`. It does not move the `v6.0.0` or `v6.1.0` tags. KAR semantics stay `kar-1-research-1`. V5 `stateRoot` is unchanged. Composition roots are unchanged.

These packages are `6.2.0` in this tree: `@knolo/core`, `@knolo/cli`, `@knolo/langchain`, `@knolo/llamaindex`, `@knolo/semantic-ollama`, and `create-knolo-app`.

`@knolo/cli` depends on `@knolo/core` `^6.2.0`. The other `@knolo/*` dependency ranges stay `^6.0.0`. `@knolo/reflex` stays `0.2.0`. `@knolo/evidence-gate` stays `0.1.0`. `@knolo/openclaw`, `@knolo/mcp`, and `@knolo/tools` stay `0.1.0`. Rust, Python, and the ICP canister stay `5.5.1` and do not implement Cortex.

The host injects any model. Core does not call a network. `verifyCortexAnswer` checks that a trace came from the declared evidence. It does not mean the answer is true. `evidenceRoot` commits each source label, and evidence must be selected by a replayed round. A dossier matches the trace body. `SATISFIED` on a cited KAR evaluation means the evidence requirements were met. It does not mean a claim is proven.

Publishing `6.2.0`, and moving the npm `latest` dist-tag, is a separate step. Do not republish `6.1.0`.
