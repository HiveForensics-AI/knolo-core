# KnoLo Starter

```bash
npm install
npm run knolo:build
npm run dev
```

Open http://localhost:3000 and ask questions about files in `./docs`.

# Knolo V4-compatible application template

This generated app uses `@knolo/core` 4.x and V4 packs by default. The V5
foundation is available beside the unchanged retrieval path; use the CLI’s
inspect/verify commands for V4 artifacts and `knolo v5 info`, `knolo v5 health`,
or `knolo v5 studio` for read-only V5 Knowledge Images. The repository roadmap
is maintained in `docs/ROADMAP.md`.
